RepoMan bookmarklets

Drag each button onto your browser's bookmarks bar. If the bar is hidden, show it first (Chrome and Edge: Ctrl+Shift+B, or Cmd+Shift+B on a Mac). Do not click the buttons on this page; they only work from inside a Claude Project page.

Linda Prune

Deletes every doc from the Claude Project you are viewing.

Linda Import

Imports the docs in a keepers.json file into the Project you are viewing.

Linda Refresh

Prune and Import in one step. Deletes every doc first.

Using them

  1. Open a page inside your Claude Project (the address contains /project/).
  2. Click the bookmark. A small progress box appears in the top right.

Prune and Refresh delete every doc in the Project. Export with withLinda and commit the export before using them.

This page is generated from the .js files next to it by build_install.py. Edit those, not this page.
